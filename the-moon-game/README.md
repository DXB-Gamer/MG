# The Moon - Rocket Empire

A small Three.js browser game where you launch a rocket, land on the moon, and build a lunar empire.

## How to run

1. Open `C:\Users\Ali Mirza\Documents\the-moon-game` in VS Code.
2. Open `index.html` in your browser.
3. Click **Launch Rocket** to start.

## Controls

- WASD / arrow keys: move camera
- Mouse drag: rotate camera
- Click build buttons after landing to place bases on the moon
- Press `Escape` to toggle the start overlay

## Files

- `index.html` - game container and UI
- `style.css` - game styling
- `main.js` - Three.js game logic
